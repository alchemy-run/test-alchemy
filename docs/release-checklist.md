# Release Checklist

Before releasing a new version, ensure all of the following steps are completed:

- [ ] Update version number in package.json
- [ ] Update CHANGELOG.md with release notes and date
- [ ] Run full test suite and verify all tests pass
- [ ] Build and verify artifact generation
- [ ] Ensure documentation is up to date and reflects changes in the release
- [ ] Create a signed git tag with the version number
