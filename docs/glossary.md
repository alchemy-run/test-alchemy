# Glossary

**Acceptance criteria** are the specific, measurable conditions that must be met for an issue or task to be considered complete and ready for code review.

**Factory** refers to the alchemy-org software factory, which is an automated system that manages development workflows, including pull request handling and issue resolution.

**Issue** is a GitHub issue used to track bugs, feature requests, enhancements, or other work items within the repository.

**Pull request** is a GitHub mechanism for proposing changes to the codebase, allowing for code review and discussion before merging into the main branch.

**Release** is a published version of the software made available to users, typically accompanied by version bumps, changelog updates, and tagged git commits.

**Semantic versioning** is a versioning scheme (major.minor.patch) that conveys information about backwards compatibility through version numbers.
